## 实现方案

目标是在 `FormTable` 的插槽类型中同时支持：

- 明确声明的 `header`、`toolbar`、`footer`
- 所有以 `table` 开头的插槽名
- 所有以 `form` 开头的插槽名

### 修改

在 `packages/element/components/form-table/src/FormTable.vue:49-50` 将当前必须带连字符的类型：

```ts
type TableExtentsSlots = `table-${string}`;
type FormExtentsSlots = `form-${string}`;
```

改为任意以前缀开头：

```ts
type TableExtentsSlots = `table${string}`;
type FormExtentsSlots = `form${string}`;
```

现有 `defineSlots` 中的两个模板字面量索引签名保持不变：

```ts
[Ta: TableExtentsSlots]: (...args: any) => any;
[F: FormExtentsSlots]: (...args: any) => any;
```

这样会接受 `table-name`、`tableName`、`form-item`、`formItem`，也包含裸名称 `table` 和 `form`。当前运行时逻辑 `key.startsWith(name)` 已经与该规则一致，无需修改。

### 验证

运行项目现有的 TypeScript/Vue 类型检查，确认 `defineSlots` 的模板字面量索引签名可正常编译，且没有引入新的类型错误。

> 如果你的实际约定仍然只允许 `table-xxx` / `form-xxx`，那么当前代码已经实现，无需修改；本方案针对“所有以 table/form 开头”的字面需求。
